# Алекс-Авто — Экспресс-замена масла

Лендинг сети сервисов экспресс-замены масла в Оренбурге (`aleks-auto.com`).

## Структура проекта
- `index.html` — основной файл лендинга (разметка, встроенные стили и векторная графика)
- `package.json` — скрипты запуска локального окружения
- `aleks-auto-backup.tar.gz` — оригинальный бэкап сайта

## Локальный запуск
Для запуска локального сервера:
```bash
npm run dev
```
Сайт будет доступен по адресу: `http://localhost:3000`
